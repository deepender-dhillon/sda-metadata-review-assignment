## Issues Identified During Quality Review

The following issues must be corrected before the submission can be approved:

### 1. Missing Data Owner Name

The submission lists the designation (**Manager, MIS**) but not the name of the officer responsible for this dataset.

**Required Action:** Please provide the full name of the designated data owner.

### 2. Incorrect Date Format

The submission currently records the **"last updated"** date as:

```text
30-11-2024
```

The SDA registry requires all dates in **YYYY-MM-DD** format.

**Required Correction:**

```text
2024-11-30
```

## Submission Update Instructions

To make this easier:

1. Log in to the metadata portal.
2. Open submission **META-010**.
3. Update the two fields identified above.
4. Submit the revised version.

> No other part of the submission needs to change.
